# SEO Master Codebase Audit (2026-10-09)

## Architecture

| Aspect | Implementation |
|---|---|
| Framework | Next.js 14.2 App Router, React 18, TypeScript, Tailwind. Fully static (SSG); `dynamicParams = false` on `/blog/[slug]`, so unknown slugs 404 |
| Hosting | Vercel; image optimisation off (`images.unoptimized`), sources pre-sized WebP |
| Routes | `/` · `/blog` · 582 hand-written guides at `src/app/blog/<slug>/page.tsx` · 447 JSON articles via `src/app/blog/[slug]/page.tsx` (143 things-to-do + 304 cluster articles in `src/content/<cluster>/`) · `/packages` + 53 package pages (36 states/UTs, 4 circuits, 13 styles) from one template · 8 category hubs · `/destinations` · commercial (`/best-travel-agency-in-india`, `/plan-your-trip`) · utility (about, contact, editorial-policy, image-credits [noindex], newsletter, write-for-us) |
| Data layer | `blog-posts.ts` (cards/titles), `all-states-data.ts` + `state-hub-children.json` (geography), `destination-profiles.ts` (13 answer-first state profiles), `travel-styles-data.ts`, `combo-packages.ts`, cluster indexes `*-index.json`, link maps `*-links.ts`, `itinerary-links.ts` (new) |
| Metadata | Per-page `metadata` exports; root template `%s \| Kudozz Club`; absolute titles when the suffix would exceed 65 chars; `pageSocial()` for OG/Twitter |
| Structured data | Root `@graph` Organization + WebSite (`#organization`, `#website`); per page BlogPosting / WebPage / CollectionPage / ItemList / FAQPage / BreadcrumbList / TouristDestination / TouristAttraction / Service |
| Breadcrumbs | Guides: `GuideBreadcrumb` (Home › Destinations › State › Place). Things to do: same trail + "Things to Do" (fixed this pass). Cluster articles: Home › Category hub › Parent › Article. Packages: Home › Packages › Page |
| Sitemap | `src/app/sitemap.ts` → `/sitemap.xml`; identical static copy `public/sitemap-pages.xml` generated by `prebuild`. 1,101 URLs, lastmod from `blog-lastmod.json` (synced by `scripts/seo-audit/sync-lastmod.py`) |
| Robots | `src/app/robots.ts`: allow all, disallow `/api/`, `/admin/`; lists both sitemaps |
| Redirects | `next.config.js`: `/blog/` → `/blog`; Vercel 308s trailing slash and HTTP→HTTPS (verified live) |
| CTAs | `GuideTripCTA` (every guide + things-to-do), `MobileStickyCTA` (site-wide), package `FinalCta`, cluster article CTAs; all → `/plan-your-trip?destination=…&from=…` |
| Forms | `/api/plan-trip`, `/api/contact`, `/api/newsletter`, `/api/write-for-us` → `src/lib/mailer.ts` (nodemailer/Gmail) |
| Fonts | `next/font` self-hosted (Playfair, Source Serif 4 not preloaded, DM Sans), `display: swap` |
| Analytics | GA4 via `next/script` afterInteractive |
| Shared JS | 86.9 kB first-load shared |
| llms.txt | `/llms.txt` (33 KB summary) + `/llms-full.txt` (full catalogue), both static in `public/` |

## Technical strengths
- Static HTML for every page; no client-side rendering of content.
- One canonical per page, self-referencing, all 1,102 match their URL; no duplicate titles, descriptions or H1s.
- Zero broken internal links, zero orphans; every guide links to its package and Plan My Trip.
- Unified entity graph via `@id`; breadcrumbs generated from the same data as the visible trail.
- Fonts self-hosted with size-adjusted fallbacks (low CLS risk).

## Where changes belong
- **Global:** `layout.tsx` (Organization, defaults), `sitemap.ts`, `robots.ts`.
- **Templates:** `src/app/blog/[slug]/page.tsx`, `AdventureArticle.tsx` (all clusters), `src/app/packages/[slug]/page.tsx`, `GuideTripCTA.tsx`, `GuideBreadcrumb.tsx`.
- **Data:** descriptions and titles in each guide's `page.tsx` or JSON; link maps in `src/lib/*-links.ts`.
- **Tooling:** `scripts/seo-audit/` (`crawl.py`, `review-batch.py`, `check-decisions.py`, `apply-decisions.py`, `build-inventory.py`, `sync-lastmod.py`, `codemod-guide-schema.py`).

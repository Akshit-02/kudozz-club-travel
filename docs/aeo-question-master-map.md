# AEO Question Master Map (2026-10-09)

Each question family has one answering page type, so multiple pages don't answer the same question in the same context. Per-cluster question maps: `*-aeo-map.md` (adventure, beach, wildlife, spiritual, heritage, hill-station, nature, road-trips, things-to-do).

Answer formats in use: quick-answer box (things to do, cluster articles, style packages), "At a glance" facts box (guides), FAQ section with FAQPage schema (1,094 pages), comparison tables (cluster articles, style packages), day-by-day plans (guides, itineraries).

## Destination questions → owner

| Question | Owner page type | Section |
|---|---|---|
| What is {place} / where is it / what is it known for? | destination guide | intro + "Why {place}?" |
| What is the best time to visit {place}? | destination guide | "Best Time to Visit" (season table) |
| How do I reach {place}? (air, rail, road; distances) | destination guide | "How to Reach" |
| How many days are enough for {place}? | destination guide FAQ; itinerary page if one exists | |
| What are the best things to do / places to visit in {place}? | things-to-do article | quick answer (ranked list) |
| What to do in {place} with one day? | things-to-do article | "With one day" |
| Is {place} good for families / couples / solo travellers? | things-to-do article | "By type of traveller"; state package FAQs (family/honeymoon fit) |
| How much does a trip to {place} cost? | destination guide | "Budget Breakdown" (estimates, dated) |
| Where should I stay? | destination guide | "Where to Stay" |
| Do I need a permit? | destination guide (permit box); state hub | e.g. ILP for Mizoram, Manipur, Nagaland, Arunachal; PAP for foreigners |
| What should I know / tips before visiting? | destination guide "Essential Tips"; things-to-do "Practical tips" | |
| What can I combine {place} with? | things-to-do "Nearby"; guide CTA itinerary link | |

## Gaps
- Origin-city questions ("Kashmir trip from Delhi: how?") are answered inside guides' "How to Reach", not as standalone pages, which is deliberate.
- Price questions can't be answered with Kudozz prices until the business publishes indicative ranges.

# Kudozz Club — Commercial Keyword Map (Delta)

**Date:** 2026-09-21 (expanded from the 2026-09-21 initial version — now covers all 36 built state pages instead of 5 examples)
**Relationship to `keyword-map.md`:** That file is unchanged and remains the authority for the 583 existing informational/editorial pages. This file maps *only* the commercial page types built this session (`/packages/*`) — it is additive, not a replacement.
**Method:** Primary keyword is the uniform `<state> tour packages` pattern validated in `travel-agency-keyword-research.md` §2. Secondary keywords are **not** a blanket template — each state's secondary keywords reflect that state's actual established travel character (the same character `keyword-map.md` already documents for the informational guide), so as not to keyword-stuff an irrelevant term (e.g. "honeymoon" is only attached to states with a real honeymoon-travel identity, not applied uniformly to all 36). No search-volume numbers are claimed — none were sourced.
**Cannibalization check:** every row was checked against the existing 583 URLs. Every state pair shares an entity (the state) but not a primary keyword or intent — the blog guide targets "travel guide / places to visit / itinerary" (informational), the package page targets "tour packages / holiday packages" (commercial). This split pattern is what prevents cannibalization across all 36 rows.

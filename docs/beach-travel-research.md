# Beach Travel: research notes and sources

Research done on 25 September 2026 with live web searches. These notes record the facts that change over time, where each came from, and how the articles phrase them. The articles quote no prices. Rules that change (swimming bans, driving on the sand, boat seasons, Blue Flag status) are described as current at the time of writing, with a prompt to check before travel.

## Search intent findings

- **"Beach travel in India" and "beach tourism in India" return different kinds of pages.**
  - "Beach tourism" results include government and academic pages on Blue Flag, BEAMS and coastal rules.
  - "Beach travel" returns destination lists.
  - So the hub takes "beach travel", and beach tourism has its own explainer.
- **"Best beach destinations" and "best beaches" are distinct.**
  - "Best beach destinations" lists places (Goa, the Andamans, Varkala).
  - "Best beaches" lists individual beaches (Radhanagar, Palolem).
- **"Best beaches in X" and "beach travel in X" return the same results for every state.** So each state gets one page.
- **Monthly and seasonal queries ("best beaches in December") overlap heavily.** They return the same coasts, so one month-by-month page covers them.
- **City-origin searches don't justify a page per city.** Mumbai, Bengaluru, Kolkata and Chennai show real demand, but each would only repeat a few beaches, so they are sections in Beach Trips in India.

## Deliberately left out

- **Prices** (boat rides, water sports, stays), because resellers quote conflicting figures.
- **Named resorts and hotels.**
- **An exact, final list of Blue Flag beaches.** Sources differ and certification is renewed every year, so the articles say "have held certification".
- **Ferry, boat and helicopter timetables** for the islands.
